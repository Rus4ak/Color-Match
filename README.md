# Color Match

A simple 3D game where the player catches falling shapes matching the basket's current color.

## Gameplay

https://github.com/user-attachments/assets/bd985217-3fc5-4f4d-bf1c-b2c1eac6c263

## Features

- Difficulty selection
- Random shape colors
- Color matching gameplay
- Score system
- Timer
- Sound effects
- Visual feedback

## Controls

- A/S - Move the basket

Unity 6.x
